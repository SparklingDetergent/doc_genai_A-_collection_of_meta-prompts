

**対策の考え方**
古いモデルは、学習時点の知識でキーワードを作ってしまい、古い製品名・バージョン・用語に固定されます。なので「自分の知識でキーワードを作らない。検索結果から語彙を拾って次のキーワードを作る」という段階式にします。

**プロンプト(コピペ用)**

```
調べものは、自分の記憶に頼らず、検索結果から最新の語彙を拾って段階的に絞る方式で進めて。
自分の知識は古い可能性があるので、バージョン名・製品名・用語・年を自分で決めて検索してはいけない。

【段階1:広く探る】
1. まず、分野を表す基礎単語を1〜2語だけで web_search する。
   (例:「ピコクロー」「Playwright」のように、自分で足した修飾語なし)
2. 「最新」「2024」など年や新しさを示す語は、あえて付けない。付ける場合も検索結果を見てから。

【段階2:語彙を拾う】
3. 結果のタイトル・スニペットから、次の情報を書き出す:
   - 現在使われている正式名称・製品名・バージョン
   - 日付(新しい順に注目)
   - よく出てくる関連用語
4. 自分の知識と食い違う語が出たら、検索結果の方を正とする。

【段階3:絞って再検索】
5. 拾った語彙だけを使い、2〜4語でもう一度 web_search する。
6. 必要なら、さらに結果から語彙を拾って最大1回だけ再検索。
   検索は合計3〜4回まで。

【URL選定】
7. 日付が新しく、公式サイト・ドキュメント・一次情報のURLを2〜4件選ぶ。
8. 日付が古い・不明なページしかない場合は、その旨を明記する。
9. duckduckgo.com/l/?uddg=... 形式なら実URLにデコードする。

【フェッチ】
10. 選んだURLを1件ずつ web_fetch で開き、本文を読む。
11. 本文中の更新日・バージョンを確認し、古ければ別URLも試す。
12. 失敗したら次の候補へ。URLの推測や自作は禁止。

【回答】
13. fetchした本文だけを根拠に答える。
14. 根拠URL、ページの更新日、取得日を添える。
```

**ポイント**
- 1回目は「分野の単語だけ」で検索し、現在の用語を検索結果から教えてもらう形にしています。
- 「最新」などの語は、DuckDuckGoでは逆にノイズになりやすいので、最初は付けません。
- 最後にフェッチ本文の更新日を確認させることで、古い情報の取りこぼしを二重に防ぎます。
