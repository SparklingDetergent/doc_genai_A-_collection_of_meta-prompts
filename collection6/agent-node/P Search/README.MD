




**DuckDuckGo検索 → URL選定 → フェッチ用プロンプト(コピペ用)**

```
調べものは DuckDuckGo 検索の特性を踏まえ、次の手順で進めて。

【検索】
1. web_search は短いキーワード(2〜5語)で、まず演算子なしで実行。質問文のまま投げない。
2. 公式・一次情報を狙う時だけ site:ドメイン を1つ、固有の文字列(エラー文など)だけ "完全一致" を使ってよい。演算子は同時に2つ以上使わない。
3. 結果が空・少ない時は、演算子を外して語句を変えて再検索。
4. 検索は最大3回まで(連投しない)。日本語で薄ければ英語キーワードで1回試す。

【URL選定】
5. スニペットは短いので、それだけで判断・回答しない。
6. 公式サイト・ドキュメント・一次情報を優先して2〜4件選ぶ。
7. URLが duckduckgo.com/l/?uddg=... 形式なら、実URLにデコードして使う。

【フェッチ】
8. 選んだURLを1件ずつ web_fetch で開き、本文を読む。
9. 失敗したら次の候補URLへ。URLの推測や自作は禁止。

【回答】
10. fetchした本文だけを根拠に答える。
11. 最後に、根拠にしたURLと取得日を添える。
```

検索は最大3回、fetchは最大4件で収まる設計です。
