Project Sheet


| 分類 | シート名 | 名称 (英語表記) | 具体的な使い方の説明 |
| :--- | :--- | :--- | :--- |
| **【管理・全体像】系** | 🏁 **SUM** | まとめ・概要<br>(Summary) | プロジェクトの目的、対象システム、主要メンバー、大まかなスケジュールなど「全体像」を記載する場所です [1]。 |
| | 📅 **WBS** | タスク一覧<br>(Work Breakdown Structure) | 自分自身が「今日・今週やるべきこと」のアクションアイテムをステップ順に並べる場所です [1]。 |
| | ⚠️ **ISS** | 課題・リスク管理<br>(Issue) | バグ、不明点、仕様の考慮漏れなど、「後から解決・決断しなければならない問題」をリストアップする場所です [1]。 |
| | ❓ **QNA** | 質問・回答待ち<br>(Q&A) | 顧客や他チームへ「質問している最中の事柄」と「その回答」を管理する場所で、未回答の放置を防ぎます [1]。 |
| | ⏳ **HIS** | 決定事項ログ<br>(History) | 「◯月◯日、要件定義の変更承認」「◯月◯日、本番リリース」など、プロジェクトの歴史（イベントと日付）を1行ずつ残す場所です [1]。 |
| | 🔄 **KPT** | ふりかえり<br>(Keep, Problem, Try) | プロジェクトの節目や週末に、「良かったこと（Keep）」「悪かったこと（Problem）」「次に試すこと（Try）」をメモし、自分のスキルアップに繋げる場所です [2]。 |
| **【作業・一次情報】系** | 📝 **LOG** | 日報・作業生ログ<br>(Log) | とにかくその日、その瞬間に起きたこと、やったことを時系列で殴り書きする「作業の生ログ」シートです [3]。 |
| | 🗣 **MTG** | 打合せメモ<br>(Meeting) | 会議や朝会中にリアルタイムでメモを取る場所で、ここから後に正式な議事録へアウトプットします [3]。 |
| | ✉️ **MSG** | メール・チャット証跡<br>(Message) | 「言った・言わない」を防ぐため、重要な指示や合意がなされたメール・チャットの発言をそのままコピペして残す場所です [3]。 |
| **【インフラ・情報資産】系** | 🌐 **ENV** | 環境・アカウント情報<br>(Environment) | 開発、検証、本番環境の各種URL、IPアドレス、サーバー名、テスト用アカウント（ID）などを集約する場所です [3]。 |
| | 🔗 **LNK** | ドキュメント・ファイルリンク<br>(Link) | 共有サーバー内にある正式な設計書、仕様書、関連するWebサイトのURLやファイルパスを整理しておく場所です [3]。 |
| | 📖 **GLO** | 用語集・データ定義<br>(Glossary) | 業務特匹の専門用語、社内略称、システム上のステータスコード（例: 0=未処理、1=処理中）の意味を書き留める場所です [3]。 |
| | 🔒 **SEC** | セキュリティ・権限<br>(Security) | ロール（閲覧権限、管理者権限など）のマトリクスや、IP制限、認証方式など、システムで最もデリケートな仕様のメモを残す場所です [4]。 |
| | ⚙️ **INI** | 初期データ・マスタ<br>(Initialization) | システム稼働時に最初に入っていなければならないマスタデータや、環境変数（.env）の設定値を書き留める場所です [4]。 |
| **【設計・技術分析】系** | 🏗 **INF** | インフラ構成図<br>(Infrastructure) | サーバー、ネットワーク、外部システムとの連携など、ハードウェア・インフラ寄りの構成をエクセルの罫線で描く場所です [5]。 |
| | 🌊 **DFD** | データフロー<br>(Data Flow Diagram) | 画面の動き（A画面→B画面）や、データの流れる順序（API→バッチ→DB）など、ソフトウェア寄りの動きを罫線と文字で描く場所です [5]。 |
| | 💻 **SRC** | ソースコード・Grep<br>(Source) | 調査したソースコードの該当箇所、Grep（検索）結果、関数やクラスの処理ロジックを貼り付けて分析する場所です [5]。 |
| | 🔍 **ERR** | エラーログ・例外分析<br>(Error) | 開発中に出現した謎のエラーコードやスタックトレースと、その原因・対策をひたすらコレクションする場所です [4]。 |
| | 🛠 **CMD** | SQL・コマンド・Tips<br>(Command) | 調査で使った複雑なSQL文や、Linuxコマンド、エラーの解決方法など、後で「使い回せる技術資産」をストックする場所です [5]。 |
| | 🤖 **GAI** | AIプロンプト・回答<br>(Generative AI) | ジェネレーティブAIとやり取りした会話履歴、役立ったプロンプト、出力されたコードのプロトタイプを貼り付ける場所です [5]。 |
| | 🧪 **TST** | 検証結果・エビデンス<br>(Test) | 自分用の単体テストや疎通確認のスクショを貼ったり [6]、性能テストの処理時間やAPIのレスポンス結果など「実際に動かした事実」の数値を記録する場所です [4]。 |
| | 📋 **REV** | レビュー指摘・修正方針<br>(Review) | コードレビューや設計書レビューで、先輩や有識者から「ここ直して」と言われた内容と、その修正方針をメモする場所です [4]。 |
| **【業務・発展】系** | 🚀 **REQ** | 要求・要望メモ<br>(Requirement) | 正式な「要件」になる前の、顧客がつぶやいた「こうなったらいいな」や、ビジネス背景を忘れないように書き留める場所です [7]。 |
| | 🎨 **UXD** | UI画面レイアウト<br>(User Experience Design) | 「画面のここにボタンが欲しい」「この並び順は使いにくい」など、操作性や見た目に関するフィードバック・アイデアをストックする場所です [7]。 |
| | 🚚 **MIG** | データ移行・コンバート<br>(Migration) | 旧システムから新システムへデータを引っ張ってくる際の、テーブルの紐付け（マッピング）や、移行ツールの実行メモを残す場所です [4]。 |
| **【退避】系** | 🗑 **DEL** | スクラップ・旧仕様<br>(Delete) | 仕様変更によってボツになったアイデア、古いコードメモなどを、消さずに「念のため」退避させておく場所です [8]。 |
